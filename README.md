# Arcade Combat

Un jeu de combat d'arcade jouable directement dans le navigateur, sans dépendance :
deux combattants, coups, saut, garde, boule de feu et une IA. Premier à 2 victoires.

## Jouer

Ouvrez `index.html` dans un navigateur (ou double-cliquez sur le fichier).

- **Entrée** : lancer le match / rejouer
- **A / D** : bouger
- **W** : sauter
- **S** : garder (réduit les dégâts)
- **J** : coup de poing
- **K** : coup de pied
- **L** : boule de feu

Tout le code est contenu dans `index.html` (HTML, CSS et JavaScript).
